# Links from https://www.nj.gov/dca/codes/codreg/ucc.shtml (added 2026-09-04)

**Note:** the section above (`current.shtml`) is DCA's "adopted model codes" cross-reference page
-- it only lists subchapters that adopt an external I-Code (3, 6, 7, 12), not a full table of
contents, which is why several N.J.A.C. 5:23 subchapters were missing from it despite existing.
This page (`ucc.shtml`, itself linked from the section above) is the actual subchapter index: all
17 N.J.A.C. 5:23 subchapter PDF links, one per subchapter. Re-checked `NJ/pdfs/` against this list
2026-09-04 and found two subchapters genuinely missing -- **`njac_5_23_10.pdf`** (Radon Hazard
Subcode) and **`njac_5_23_12A.pdf`** (Optional Elevator Inspection Program) -- both now downloaded
and ingested; see `docs/AllDevFlow.md`'s Phase 1 "subchapter 10" note and `PLAN.md` for details.
With those two added, the corpus now has all 17 subchapters listed below.
